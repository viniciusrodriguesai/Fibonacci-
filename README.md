# Fibonacci exercises

Python exercises developed while studying the Cod3r course. The scripts preserve successive iterative and recursive approaches to the Fibonacci sequence.

## Run an example

Python 3 and the standard library are sufficient:

```bash
python Codigos_Fibonacci/fibonacci_v6.py
```

This example prints the first 20 terms, beginning with `0, 1, 1, 2, 3, 5`. Other versions are in [`Codigos_Fibonacci`](Codigos_Fibonacci); inspect each script for its inputs and stopping condition.

## Scope

This is a historical learning repository. The versions are independent exercises with different interfaces; they do not provide a shared command-line application or consistent input validation. Recursive versions are intended for small inputs.
